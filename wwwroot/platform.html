Multi-Cloud Interface Architecture

Traditional CSPMs require separate codebases for each cloud. Nexus utilizes a strict C# Interface (`ICloudScanner`). The Dependency Injection container automatically registers plugins for AWS, Azure, GCP, Oracle, and Kubernetes, allowing the `/api/scan` endpoint to remain entirely cloud-agnostic.

builder.Services.AddTransient<ICloudScanner, AwsScanner>();
builder.Services.AddTransient<ICloudScanner, AzureScanner>();
builder.Services.AddTransient<ICloudScanner, GcpScanner>();
builder.Services.AddTransient<ICloudScanner, OracleScanner>();
builder.Services.AddTransient<ICloudScanner, KubernetesScanner>();

True Multi-Tenancy

Nexus operates as a centralized Enterprise SaaS. Every API call made from the dashboard includes a cryptographically bound X-Tenant-ID header representing the authenticated user.

Entity Framework Core intercepts this header and applies strict WHERE TenantId = @id clauses to every SQLite database query, ensuring 100% data isolation. Scans, threats, and automated remediations are perfectly sandboxed from other platform users.

Identity Governance (IGA)

Nexus separates operational scanning from user identity. Authentication is handled via Google SSO. Dashboard privileges (Viewer vs. Admin) are governed dynamically via a listener attached to our Firebase Firestore NoSQL cloud database.

A separate application—the DxO Portal—allows corporate security officers to review and approve privilege escalation requests, instantly unlocking SOAR capabilities in the client dashboard.

Shift-Left IaC Scanning

Security shouldn't wait for production. The Nexus dashboard includes a drag-and-drop Pre-Flight Scanner.

Engineers can upload raw Terraform (.tf) or Kubernetes (.yaml) files. The ASP.NET engine parses the configurations in memory and runs the exact same rule-evaluators used for live environments, catching misconfigurations before deployment.
