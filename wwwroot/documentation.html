What is Nexus?

Nexus is an enterprise-grade Cloud Security Posture Management (CSPM) engine built entirely on ASP.NET Core and Firebase. It actively audits cloud infrastructure to detect dangerous misconfigurations before attackers can exploit them.

Unlike traditional tools that simply generate alerts, Nexus features a Security Orchestration, Automation, and Response (SOAR) module. This allows the system to actively reach into the cloud and patch vulnerabilities—like open SSH ports or wildcard IAM admins—in real-time.

It also features an integrated Generative AI Analysis Engine to explain threat vectors to junior analysts, and an IaC Pre-Flight Scanner to catch vulnerabilities in Terraform and Kubernetes manifests before they are ever deployed.

Understanding Multi-Cloud

A "Multi-Cloud" architecture means an organization relies on multiple cloud providers rather than locking into just one. While this provides incredible redundancy, it creates massive security blind spots.

AWS IAM & EC2
Azure Resource Graph
GCP Asset Inventory
K8s Cluster RBAC

Nexus solves the multi-cloud problem by abstracting the cloud APIs using a C# interface (`ICloudScanner`). This normalizes telemetry from AWS, Azure, GCP, and Kubernetes into a single pane of glass.

Identity Governance & Administration (IGA)

Security tools require security. Nexus uses a completely decoupled, serverless Identity Governance architecture backed by Firebase Firestore to ensure role-based access control (RBAC) is strictly enforced and resilient to local database failures.

1. Application Flow

Users authenticate via Google Single Sign-On (SSO). By default, all users are restricted to Viewer Mode. To gain SOAR remediation privileges, they must submit a justification through the `apply-admin.html` portal.

2. DxO Corporate Approval

Applications are sent to the parent company's dedicated governance web app (`dxo-portal.html`). A corporate security officer reviews the request and clicks Approve, which updates the live Firestore database.

3. Dynamic Dashboard Unlocking

The Nexus CSPM Dashboard maintains a real-time listener with Firestore. The moment an application is approved, the UI dynamically unlocks, granting the user the Red Admin Badge and activating cloud remediation buttons.

Why Use Nexus?

Eliminate Alert Fatigue

Stop drowning in endless security alerts. Nexus groups findings by severity and allows 1-click automated remediation to clear the queue instantly.

Continuous Compliance

Historical SQLite logging ensures you can always prove to auditors that your infrastructure was secure at any point in time, independent of your Firebase Identity architecture.

Getting Started

  1. Ensure you have the .NET 8.0 SDK installed on your local machine.
  2. Create a Firebase Project and enable Google Authentication and Firestore.
  3. Run the backend C# server using: dotnet run
  4. Log in to the Web App using your Google Account in the top right corner.
  5. Open your profile dropdown and submit an Admin Application.
  6. Open the DxO Portal to approve your own application.
  7. Navigate to the Command Center and click Run Multi-Cloud Scan!
