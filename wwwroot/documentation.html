What is Nexus?

Nexus is an enterprise-grade Cloud Security Posture Management (CSPM) engine built entirely on ASP.NET Core and Entity Framework. It actively audits cloud infrastructure to detect dangerous misconfigurations before attackers can exploit them.

Unlike traditional tools that simply generate alerts, Nexus features a Security Orchestration, Automation, and Response (SOAR) module. This allows the system to actively reach into the cloud and patch vulnerabilities—like open SSH ports or wildcard IAM admins—in real-time.

Understanding Multi-Cloud

A "Multi-Cloud" architecture means an organization relies on multiple cloud providers (like Amazon AWS, Microsoft Azure, and Google Cloud GCP) rather than locking into just one. While this provides incredible redundancy and cost savings, it creates massive security blind spots.

AWS IAM & EC2 Security
Azure Resource Graph
GCP Asset Inventory

Nexus solves the multi-cloud problem by abstracting the cloud APIs using a C# interface (`ICloudScanner`). This normalizes telemetry from all three providers into a single pane of glass.

Why Use Nexus?

Eliminate Alert Fatigue

Stop drowning in endless security alerts. Nexus groups findings by severity and allows 1-click automated remediation to clear the queue instantly.

Continuous Compliance

Historical SQLite logging ensures you can always prove to auditors that your infrastructure was secure at any point in time.

Getting Started

  1. Ensure you have the .NET 8.0 SDK installed on your local machine.
  2. Configure an AWS IAM user with `SecurityAudit` and `AmazonEC2FullAccess` permissions.
  3. Run the backend server using the terminal command: dotnet run
  4. Log in using your Google Account in the top right corner.
  5. Navigate to the Command Center and click Run Multi-Cloud Scan.

API Reference

The engine is fully headless. You can trigger audits programmatically via standard REST endpoints.

POST /api/scan/run

Initializes the multi-cloud ICloudScanner interface and loops through AWS, Azure, and GCP plugins.

fetch('/api/scan/run', {
    method: 'POST'
}).then(res => res.json());
POST /api/remediate

Accepts a RuleCode and ResourceIdentifier to automatically patch a live cloud environment.

fetch('/api/remediate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ resourceIdentifier: "sg-123", ruleCode: "EC2_SSH_OPEN" })
});
